
ALGORITHM FOR TCP SERVER AND CLIENT

SERVER (server.c)

1. Start the program.
2. Include stdio.h, stdlib.h, string.h, unistd.h, sys/socket.h, arpa/inet.h and sys/types.h.
3. Define port number as 8080.
4. Declare sockfd, new_sock, pid, filename[], buffer[], fp, server_addr and client_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, INADDR_ANY and port 8080.
7. Bind the socket using bind().
8. Listen for client connections using listen().
9. Display "File Server Running".
10. Repeat continuously:
    - Accept client connection using accept().
    - Create a child process using fork().
    - In the child process:
      a. Close the server socket.
      b. Receive filename using recv().
      c. Open the file using fopen() in read mode.
      d. Send server PID to the client.
      e. If file does not exist, send an error message.
      f. Otherwise, read contents using fgets().
      g. Send file contents using send().
      h. Close the file and client socket.
      i. Terminate child process using exit().
    - In the parent process, close the client socket.
11. Stop the program.

---------------- CLIENT (client.c) ----------------

1. Start the program.
2. Include stdio.h, string.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, filename[], buffer[] and server_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, port 8080 and IP 127.0.0.1.
7. Connect to the server using connect().
8. Read the filename from the user.
9. Send the filename using send().
10. Receive the server response and file contents using recv().
11. Display the received file contents.
12. Continue receiving until the server closes the connection.
13. Close the socket using close().
14. Stop the program.
