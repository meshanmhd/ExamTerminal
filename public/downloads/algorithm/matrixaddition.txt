
ALGORITHM FOR TCP SERVER AND CLIENT

SERVER (server.c)

1. Start the program.
2. Include stdio.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, new_sock, r, c, a[][], b[][], sum[][], i, j, server_addr and client_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, INADDR_ANY and port 8080.
7. Bind the socket using bind().
8. Listen for client connections using listen().
9. Accept the client connection using accept().
10. Receive rows, columns, Matrix A and Matrix B using recv().
11. Add the matrices using nested for loops:
    - Repeat for i = 0 to r - 1.
    - Repeat for j = 0 to c - 1.
    - Calculate sum[i][j] = a[i][j] + b[i][j].
12. Send the resultant matrix using send().
13. Close the client and server sockets using close().
14. Stop the program.

---------------- CLIENT (client.c) ----------------

1. Start the program.
2. Include stdio.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, r, c, a[][], b[][], sum[][], i, j and server_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, port 8080 and IP 127.0.0.1.
7. Connect to the server using connect().
8. Read rows, columns, Matrix A and Matrix B using scanf().
9. Send rows, columns, Matrix A and Matrix B using send().
10. Receive the resultant matrix using recv().
11. Display the resultant matrix.
12. Close the socket using close().
13. Stop the program.
