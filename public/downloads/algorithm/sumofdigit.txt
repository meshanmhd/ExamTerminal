
ALGORITHM FOR TCP SERVER AND CLIENT

SERVER (server.c)

1. Start the program.
2. Include stdio.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, new_sock, num, temp, digit, sum, server_addr and client_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, INADDR_ANY and port 8080.
7. Bind the socket using bind().
8. Listen for client connections using listen().
9. Accept the client connection using accept().
10. Receive the number using recv().
11. Initialize sum = 0 and temp = num.
12. If num is negative, convert it into a positive number.
13. Calculate sum of digits using a while loop:
    - Repeat while temp > 0.
    - Extract digit = temp % 10.
    - Calculate sum = sum + digit.
    - Update temp = temp / 10.
14. Send the sum using send().
15. Close the client and server sockets using close().
16. Stop the program.

---------------- CLIENT (client.c) ----------------

1. Start the program.
2. Include stdio.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, num, sum and server_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, port 8080 and IP 127.0.0.1.
7. Connect to the server using connect().
8. Read a number using scanf().
9. Send the number using send().
10. Receive the sum using recv().
11. Display the sum of digits.
12. Close the socket using close().
13. Stop the program.
