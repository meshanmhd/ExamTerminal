
ALGORITHM FOR TCP SERVER AND CLIENT

SERVER (server.c)

Start the program.
Include stdio.h, string.h, unistd.h, sys/socket.h and arpa/inet.h.
Define port number as 8080.
Declare server_fd, new_socket, str and server_addr.
Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
Initialize server address with AF_INET, INADDR_ANY and port 8080.
Bind the socket using bind().
Listen for client connections using listen().
Accept the client connection using accept().
Receive the string from the client using read().
Reverse the string using the library function strrev().
Send the reversed string to the client using write().
Display the reversed string.
Close the client and server sockets using close().
Stop the program.

---------------- CLIENT (client.c) ----------------

Start the program.
Include stdio.h, string.h, unistd.h, sys/socket.h and arpa/inet.h.
Define port number as 8080.
Declare sock, str and serv_addr.
Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
Initialize server address with AF_INET, port 8080 and IP address 127.0.0.1.
Connect to the server using connect().
Read a string from the user using scanf().
Send the string to the server using write().
Receive the reversed string using read().
Display the reversed string.
Close the socket using close().
Stop the program.
