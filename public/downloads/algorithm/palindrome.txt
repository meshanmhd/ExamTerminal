
ALGORITHM FOR TCP SERVER AND CLIENT

SERVER (server.c)

1. Start the program.
2. Include stdio.h, string.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, new_sock, str[], result[], i, j, flag, server_addr and client_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, INADDR_ANY and port 8080.
7. Bind the socket using bind().
8. Listen for client connections using listen().
9. Accept the client connection using accept().
10. Receive the string using recv().
11. Initialize i = 0 and j = strlen(str) - 1.
12. Initialize flag = 1.
13. Compare characters using a while loop:
    - Repeat while i < j.
    - If str[i] != str[j], set flag = 0.
    - Otherwise, increment i and decrement j.
14. If flag = 1, store "Palindrome".
15. Otherwise, store "Not Palindrome".
16. Send the result using send().
17. Close the client and server sockets using close().
18. Stop the program.

---------------- CLIENT (client.c) ----------------

1. Start the program.
2. Include stdio.h, string.h, unistd.h, sys/socket.h and arpa/inet.h.
3. Define port number as 8080.
4. Declare sockfd, str[], result[] and server_addr.
5. Create a TCP socket using socket() with AF_INET and SOCK_STREAM.
6. Initialize server address with AF_INET, port 8080 and IP 127.0.0.1.
7. Connect to the server using connect().
8. Read a string using fgets().
9. Send the string using send().
10. Receive the result using recv().
11. Display Palindrome or Not Palindrome.
12. Close the socket using close().
13. Stop the program.
